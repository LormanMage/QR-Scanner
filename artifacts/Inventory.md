# Отчет: Добавление функционала для кнопки "Инвентаризация"

**Автор:** Стельмак Владислав
**Дата:** 15.11.2026  

## 1. Цель
Добавить функционал для инвентаризациии

## 2. Что было сделано
- Создан класс InventorySession, который хранит информацию об оборудовании.
- Создан экран с историей проведения инвентаризации. При нажатии на проведеную инвентаризацию открывается список просканированного оборудования.
- Создан новый экран сканера. При сканировании кода появляется информация об просканированном оборудовании.

## 3. Что было изучено
- Был изучен плагин shared preferences для локального хранения данных в формате ключ-значение на устройстве. 

## 4. Результаты
- При нажатии на кнопку открывается окно, где будут храниться история с инвентаризацией и кнопка "Начать".
- После начала инвентаризации открывается сканер, где мы сканируем коды с оборудования.
- После завершения инвентаризации она сохраняется в историю. При отмене просто возвращается на экран с историями инвентаризаций
