# Отчет: Добавление функционала кнопки "История Выдач"

**Автор:** Стельмак Владислав
**Дата:** 15.11.2026  

## 1. Цель
Добавить функционал кнопке "История Выдач"

## 2. Что было сделано
- был добавлен экран с историей выдач оборудования.
- добавлены кнопки "очистить истоию", а также кнопки "отметить возврат" и "Удалить".
- добавлен фильтр, который позволяет просмтривать только выданное оборудование. Оборудование, которое уже вернули, с этим фильтром не отображается.
- Был добавлен класс EquipmentItem, который хранит информацию об 1-й единице оборудования.
 

## 4. Результаты
- Qr-код сканируется, после подтверждения выдачи информация попадает в историю выдач.
- Статус имеет свой цвет. Серый -- оборудование вернули. Желтый -- оборудование просрочено. Красный -- выдано.
