# Отчет: Добавление функционала для кнопки "Фото из галереи"

**Автор:** Данилова Анастасия
**Дата:** 17.11.2026

## 1. Цель
Добавить возможность распознавания QR-кода с изображения, выбранного из галереи телефона.

## 2. Что было сделано
- Создан сервис `GalleryScanner` (файл `lib/gallery_scanner.dart`), который открывает галерею и распознает QR-код на выбранном изображении.
- На главный экран (`lib/main.dart`) добавлена кнопка «Фото из галереи», которая вызывает этот сервис.
- Реализована логика: после выбора фото и успешного распознавания кода, данные передаются на экран подтверждения выдачи (`IssueConfirmScreen`).
- Обработаны ошибки: если QR-код не найден или пользователь отменил выбор, выводится сообщение (SnackBar).

## 3. Что было изучено
- Была изучена библиотека `image_picker` для доступа к галерее устройства.
- Была изучена библиотека `google_mlkit_barcode_scanning` для распознавания QR-кодов на статичных изображениях.

## 4. Результаты
- При нажатии на кнопку «Фото из галереи» открывается галерея телефона.
- После выбора изображения с QR-кодом приложение распознает его и открывает экран подтверждения выдачи с данными.
- Функция успешно интегрирована в общее приложение и работает вместе с остальными кнопками.
