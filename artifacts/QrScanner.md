# Отчет: Добавление функционала для кнопки "Сканировать QR"

**Автор:** Стельмак Владислав
**Дата:** 15.11.2026  

## 1. Цель
Добавить функционал для сканера.

## 2. Что было сделано
- При нажатии на кнопку открывается камера с надписью.
- После сканирования кода появляется окно с подтверждением выдачи с отсканированной информацией и кнопками "Отмена" и "Подтвердить выдачу".
- После подтверждения выдачи возвращается на главный экран, а запись должна будет сохранятся в историю выдач.
- При отмене возвращается на экран камеры чтобы продолжить сканирование.

## 3. Что было изучено
- Была изучена библиотека mobile scanner.
- была изучена библиотека provider. Она нужна для управления состоянием и внедрении зависимостей в приложении


## 4. Результаты
- Сканер успешно работает, но пока не сохраняет отсканированный код.
